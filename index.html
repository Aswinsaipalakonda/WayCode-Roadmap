The Problem

AI coding agents are powerful. Their interfaces are still desktop-first.

CHALLENGE 01

Desktop Dependency

Autonomous LLM agents (SWE-agent, MetaGPT, OpenHands) assume a persistent desktop, terminal shell, and local development sandbox.

CHALLENGE 02

Mobile Constraints

Smartphone viewports, virtual keyboards, and touch dragging make running full desktop IDEs on mobile screens inefficient and frustrating.

CHALLENGE 03

Network Instability

Mobile connectivity drops during transit, and background process termination by mobile operating systems kills long-running agent tasks.

The core limitation isn't compute.

It's access.

Academic Defense & Viva

Key Defense Arguments for Project Panels.

Framing technical novelty, network fault-tolerance, and security for academic guides and department coordinators.

ARGUMENT 01
Why Not Existing Remote Desktop Tools?

Remote desktop tools mirror desktop layouts onto smartphones, causing severe ergonomic strain. Our system shifts interaction from Manual Code Editing to High-Level Intent Prompting.

ARGUMENT 02
Network Instability & Mobile Disconnection

By placing an asynchronous Redis message queue between Nginx and the daemon, request state is completely decoupled from mobile socket persistence.

ARGUMENT 03
Security & Scoped OAuth Tokens

Tokens are stored securely in PostgreSQL on the VPS and accessed strictly by localhost backend processes—never exposed to the mobile client.
